# C-justify_and_encrypt
This program is a little bit different than any previous program i made, it is one of the most if not the most complicated one I made.<br>
In this program with my journey with C Programming a modern approach:<br>
1. I separated every group of functions alone.
2. Used different header files, and source files.
3. Used preprocessor functions for debugging.
4. Created my makefile.
5. Used command line commands, input redirection.
6. Added getopt for implementing command line options for my program.

As for the command lines options we have three options:<br>
1. -e key: use it if you want to encrypt using Caesar Cipher with the key being a positive number with max 25.
2. -d key: use it to decrypt a file with the same method using a key.
3. -o: only to do encryption or decryption, no justifying here, if you justify a justified text it is on you 😄.
4. nothing is for the normal justification without encrypting.

use < input redirection to input your text directly.
